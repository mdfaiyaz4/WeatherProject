# WeatherProject
🌦️ AI-Powered Weather App

An AI-powered weather application that provides real-time weather updates with context-aware AI responses using Gemini 2.0. The app features a modern UI, animated weather effects, and an intelligent chatbot for user interaction.

🚀 Features

🌍 Real-time weather data (OpenWeatherMap API)

🤖 AI chatbot with contextual weather responses (Gemini 2.0)

🌈 Dynamic animated backgrounds based on weather

💬 AI typing indicator

📱 Responsive and modern UI

🛠️ Tech Stack

HTML, CSS, JavaScript

OpenWeatherMap API

Google Gemini 2.5 Flash API

⚙️ Setup
git clone https://github.com/your-username/ai-weather-app.git
cd ai-weather-app

🎯 Use Case

Smart weather checking with AI-based contextual responses and insights.
